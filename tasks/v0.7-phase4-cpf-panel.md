# v0.7 Phase 4 — CPF Panel in Expenses Tab

## Goal

Add a `CpfPanel` component to the Expenses tab showing current CPF balances and computed monthly contributions. The panel sits **above the tab bar** (above Transactions / Projections tabs).

---

## Files to create

### `src/components/expenses/CpfPanel.tsx`

`'use client'` component. Props:

```ts
interface CpfPanelProps {
  balance: CpfBalance | null;
  grossMonthlySalary: number;
  userAge: number;
}
```

Import `CpfBalance` from `@/types`. Import `getCpfContributionRate` and `getCpfAllocationRates` from `@/lib/retirement/cpf`.

**UI — when `balance !== null`:**

1. **Three balance cards in a row** (OA | SA | MA):
   - Label, amount in `S$` format (2 dp, thousands separator)
   - Small "as of {date}" below the three cards (format: `MMM YYYY` from `balance.date`)

2. **Monthly contributions row** — two sub-cards:
   - Employee contribution: `grossMonthlySalary × rates.employee` (where `rates = getCpfContributionRate(userAge)`)
   - Employer contribution: `grossMonthlySalary × rates.employer`
   - Label each: "Employee (XX%)" and "Employer (XX%)" where XX is the rate as a percentage

3. **"Update balances" button** — clicking it reveals an inline form with:
   - Three number inputs: OA, SA, MA (pre-filled with current balance values)
   - Date input (pre-filled with today's date in `YYYY-MM-DD`)
   - Save / Cancel buttons
   - On Save: call `saveCpfBalanceAction({ date, oa, sa, ma })` then hide the form (optimistic update — re-render with new values immediately without a page reload)
   - Import `saveCpfBalanceAction` from `@/app/lib/actions`

**UI — when `balance === null`:**

Show an empty state: "No CPF balance recorded yet." with the "Update balances" button to add the first entry.

**Styling:** Use the existing Tailwind v4 tokens from the project. Keep styling consistent with the rest of the Expenses tab — white card backgrounds (`bg-white`), `rounded-xl`, `shadow-sm` border style. The panel should have a heading "CPF" at the top left.

## Files to edit

### `src/app/expenses/page.tsx`

Add `getLatestCpfBalance` to the parallel fetch. Compute `userAge` from DOB. Pass both to `ExpensesClient`.

```ts
import { getLatestCpfBalance } from '@/lib/retirement/sheets';

// DOB: June 1984
function computeAge(dob: string): number {
  const [dobYear, dobMonth] = dob.split('-').map(Number);
  const now = new Date();
  let age = now.getFullYear() - dobYear;
  if (now.getMonth() + 1 < dobMonth) age--;
  return age;
}

// In the component:
const [transactions, rules, overrides, cpfBalance] = await Promise.all([
  getExpenses(), getExpenseRules(), getProjectionOverrides(), getLatestCpfBalance(),
]);
const userAge = computeAge('1984-06');
```

Pass `cpfBalance` and `userAge` as props to `<ExpensesClient>`.
