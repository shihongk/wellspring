# v0.7 Phase 5 — Retirement Page UI

## What this builds

A new `/retirement` page: server component fetches data, client component computes projections and renders a settings panel, KPI cards at retirement age, an SVG projection chart, and a one-off expenses editor.

---

## Project context

- Next.js 16.2.3 App Router. All route files need `export const dynamic = 'force-dynamic'`.
- `params` in dynamic routes is a Promise — always `await params`.
- Route Handlers use Web `Request` / `Response.json(...)` — not `NextApiRequest`.
- No module-level Sheets or Yahoo Finance singletons — instantiate per invocation (already handled in the lib files below).
- All shared types live in `src/types/index.ts`.
- Tailwind v4. SGD format: `S$1,234.56`. Custom tokens in `globals.css` — use `--color-gain`, `--color-loss`, `--color-primary`, etc.

## Files to create

### `src/app/retirement/page.tsx`

Server Component. `export const dynamic = 'force-dynamic'`.

**Imports:**
```ts
import { getLatestCpfBalance } from '@/lib/retirement/sheets';
import { getRetirementOneOffs } from '@/lib/retirement/sheets';
import { getHoldings } from '@/lib/google-sheets';
import { fetchPricesAndFx } from '@/lib/yahoo-finance';
import { toSGD } from '@/lib/fx';
import { RetirementClient } from '@/components/retirement/RetirementClient';
```

**Data fetching:**
```ts
const [cpfBalance, oneOffs, holdings, pricesAndFx] = await Promise.all([
  getLatestCpfBalance(),
  getRetirementOneOffs(),
  getHoldings(),
  fetchPricesAndFx(),
]);
```

**Compute `currentPortfolioByTicker`** (SGD value per non-CASH ticker):
```ts
const { fxRates, prices } = pricesAndFx;
const currentPortfolioByTicker: Record<string, number> = {};
for (const h of holdings) {
  if (h.ticker === 'CASH') continue;
  const p = prices[h.ticker];
  if (!p || p.price === null) continue;
  currentPortfolioByTicker[h.ticker] = toSGD(p.price * h.shares, h.currency, fxRates);
}
```

**Compute `tickerWeights`** (proportional, sums to 1):
```ts
const totalPortfolioSGD = Object.values(currentPortfolioByTicker).reduce((a, b) => a + b, 0);
const tickerWeights: Record<string, number> = {};
for (const [ticker, val] of Object.entries(currentPortfolioByTicker)) {
  tickerWeights[ticker] = totalPortfolioSGD > 0 ? val / totalPortfolioSGD : 0;
}
```

**Render:**
```tsx
return (
  <main className="ml-48 p-8 min-h-screen" style={{ backgroundColor: '#f0f9ff' }}>
    <h1 className="text-2xl font-bold text-slate-800 mb-6">Retirement</h1>
    <RetirementClient
      cpfBalance={cpfBalance}
      oneOffs={oneOffs}
      currentPortfolioByTicker={currentPortfolioByTicker}
      tickerWeights={tickerWeights}
    />
  </main>
);
```

### `src/components/retirement/RetirementClient.tsx`

`'use client'` component.

**Props:**

#### Settings state

Persist to/from `localStorage` key `wellspring_retirement_settings`. Shape:

```ts
interface LocalSettings {
  dob: string;                          // default '1984-06'
  retirementAge: number;                // default 65
  payoutStartAge: number;               // default 65
  grossMonthlySalary: number;           // default 9000
  netMonthlyCashFlow: number;           // default 3000
  tickerReturns: Record<string, number>; // default 5 for each ticker in currentPortfolioByTicker
}
```

Load on mount with `useEffect`; write on every settings change.

#### Projection computation

```ts
const projections = useMemo((): RetirementProjectionYear[] => {
  if (!cpfBalance) return [];
  const tickers = Object.keys(currentPortfolioByTicker);
  const tickerReturns: Record<string, number> = {};
  for (const t of tickers) tickerReturns[t] = settings.tickerReturns[t] ?? 5;

  const params: ProjectRetirementParams = {
    cpfStartBalances: cpfBalance,
    dob: settings.dob,
    retirementAge: settings.retirementAge,
    payoutStartAge: settings.payoutStartAge,
    grossMonthlySalary: settings.grossMonthlySalary,
    netMonthlyCashFlow: settings.netMonthlyCashFlow,
    currentPortfolioByTicker,
    tickerReturns,
    tickerWeights,
    oneOffs,
    horizonYears: 45,  // covers to age ~86
  };
  return projectRetirement(params);
}, [cpfBalance, settings, oneOffs, currentPortfolioByTicker, tickerWeights]);
```

#### KPI cards

Find the year row where `row.age === settings.retirementAge`. Show four cards:
1. **Net Worth** — `row.netWorth`
2. **Investments** — `row.investments`
3. **Total CPF** — `row.cpf.totalCpf`
4. **CPF LIFE payout** — `row.cpf.cpfLifeMonthlyPayout ?? 0` (monthly)

Format all SGD values with `S$` prefix, 2 dp, thousands separator. CPF LIFE card shows "/month".

If no row at retirement age (cpfBalance null or horizon too short), show `—`.

#### Settings panel

Collapsible (collapsed by default). Header: "Settings" with a chevron toggle.

Grid of inputs:
- **Date of Birth** — `<input type="month">` bound to `settings.dob` (format `YYYY-MM`)
- **Retirement Age** — number input, min 55 max 70
- **CPF Payout Start Age** — number input, min 65 max 70
- **Gross Monthly Salary (S$)** — number input
- **Net Monthly Cash Flow (S$)** — helper text: "income − expenses − employee CPF"
- **Per-ticker annual return (%)** — one number input per ticker in `currentPortfolioByTicker`; label = ticker symbol

All inputs update state immediately on change.

#### Projection chart

SVG area/line chart. Build it similarly to `src/components/value-history-chart.tsx` (uses `preserveAspectRatio="none"` on the SVG, manually maps data to SVG coords).

- **X-axis:** year, from first projection year to last
- **Y-axis:** SGD values, auto-scale to max `netWorth`
- **Two view modes** (toggle button above chart): "Net Worth" | "Breakdown"
  - Net Worth: single area (fill `--color-primary` at 20% opacity, stroke `--color-primary`)
  - Breakdown: stacked areas — Investments (cyan), OA (blue), SA/RA (indigo), MA (emerald), Cash Reserve (amber). Use `cpf.oa`, `cpf.sa + cpf.ra`, `cpf.ma`, `cashReserve` from each row.
- **Vertical dashed markers:**
  - Retirement year: label "Retire"
  - CPF payout start year: label "CPF LIFE" (only if different from retirement year)
- **X-axis labels:** show every 5 years
- **Y-axis labels:** abbreviated (e.g. "S$1M", "S$500K")

No external chart library — SVG only.

#### One-off expenses editor

Table below the chart. Columns: Year | Description | Amount | (delete button).

Inline "Add" form at the bottom of the table:
- Year input (number, min current year, max retirement year + 5)
- Description text input
- Amount number input (S$)
- "Add" button

On Add: generate a uuid with `crypto.randomUUID()`, call `saveRetirementOneOffAction({ id, year, description, amountSGD })`, update local state optimistically.

On Delete: call `deleteRetirementOneOffAction(id)`, update local state optimistically.

Wrap both in `useTransition`.
