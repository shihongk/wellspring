# v0.7 Phase 6 — Retirement Migration Section on Setup Page

## What this builds

A small "Migrations" section at the bottom of `/setup` with a button that adds the `CpfBalances` and `RetirementOneOffs` tabs to an existing sheet. This is for users who completed setup before v0.7 and need to add the new tabs without re-running full provisioning.

The Retirement nav link was already added in Phase 5. This is the last remaining v0.7 task.

---

## Important: how the API works

`POST /api/setup/migrate-retirement` (`src/app/api/setup/migrate-retirement/route.ts`) already exists. It:
- Reads credentials from `process.env` (not the request body)
- Returns `{ created: string[], skipped: string[] }`
- Both tabs skipped → both already existed
- Is idempotent — safe to call multiple times

**Do not pass credentials in the request body. Call with no body.**

## Files to create

### `src/components/setup/MigrateRetirementSection.tsx`

`'use client'` component. No props.

```tsx
type Status = 'idle' | 'running' | 'done' | 'already-exists' | 'error';
```

**UI:**

```
[ v0.7 Retirement Features ]
Add the CpfBalances and RetirementOneOffs tabs to your sheet.
Required for the CPF panel and Retirement page.

[ Add Retirement Tabs ]   ← button, disabled while running

Status message area (conditionally rendered below button)
```

**Status messages:**
- `running`: "Adding tabs…" (button text)
- `done`: "Retirement tabs created successfully." (green)
- `already-exists`: "Tabs already exist — nothing to do." (green)
- `error`: "Error: {message}" (red)

**onClick logic:**
```ts
const res = await fetch('/api/setup/migrate-retirement', { method: 'POST' });
const data = await res.json();
if (!res.ok) { setStatus('error'); setErrorMsg(data.error); return; }
if (data.created.length === 0) setStatus('already-exists');
else setStatus('done');
```

Style consistently with the rest of `src/app/setup/page.tsx` — white card background, same rounded border style used for `HowToGuide`.
