# Task: v0.7 Phase 5 — Retirement Page UI

## What this task builds

The new `/retirement` page UI, which combines the CPF and Retirement Projection engines to visualize long-term net worth. It includes a settings panel, an editor for one-off expenses, an interactive SVG projection chart, and KPI cards.

---

## Project Context & Rules

- **Framework:** Next.js 16.2.3 App Router (TypeScript, Tailwind CSS v4)
- **Component Split:** Server Component (`page.tsx`) handles all data fetching; Client Component (`RetirementClient.tsx`) handles state, projection computation, and rendering.
- **Engine:** Import and use `projectRetirement` from `src/lib/retirement/projections.ts`.
- **Storage:** Persist user settings to `localStorage` under the key `wellspring_retirement_settings`.

---

## Files to Create

### 1. `src/app/retirement/page.tsx`
- Create as a Server Component.
- Add `export const dynamic = 'force-dynamic';`
- Fetch the following concurrently:
  - `getLatestCpfBalance()`
  - `getRetirementOneOffs()`
  - `getHoldings()` and `fetchPricesAndFx()` (for current portfolio value by ticker).
- Render `<RetirementClient>` and pass the fetched data down as props. For `grossMonthlySalary` and `netMonthlyCashFlow`, you can pass a hardcoded baseline (e.g., `9000` salary, `3000` cash flow) which the user can override in the settings panel.

### 2. `src/components/retirement/RetirementClient.tsx`
- Create as a `'use client'` component.
- **State Management:**
  - Manage a `RetirementSettings` object in state (default DOB `'1984-06'`, retirement age 65, payout start age 65).
  - Manage per-ticker return expectations (default to `5%` for each holding).
  - Read from and write to `localStorage`.
- **Projections Engine:**
  - Compute projections synchronously in a `useMemo` calling `projectRetirement(...)`.
- **UI Layout:**
  - **Settings Panel:** Collapsible grid. Inputs for DOB (month/year), Retirement Age, CPF Payout Start Age, Salary, Net Cash Flow, and individual inputs for Ticker Returns.
  - **KPI Cards:** Display four cards showing values *at the user's retirement age*:
    1. Total Net Worth
    2. Investment Value
    3. Total CPF (OA + MA + RA)
    4. Monthly CPF LIFE Payout
  - **Projection Chart:**
    - Build an SVG area chart (similar to `ValueHistoryChart` using `preserveAspectRatio="none"`).
    - X-axis: Year (from current year to retirement age + 10).
    - Y-axis: SGD Value.
    - Modes: "Net Worth Only" (single line/area) vs. "Stacked Breakdown" (Investments | Cash | OA | SA/RA | MA).
    - Add vertical dashed markers indicating the Retirement Year and CPF Payout Start Year.
  - **One-off Expenses Editor:**
    - A small table/list showing current `oneOffs`.
    - Add an inline form (Year, Description, Amount) with an "Add" button firing `saveRetirementOneOffAction`.
    - Add a "Delete" button per row firing `deleteRetirementOneOffAction`.
    - Wrap mutations in `useTransition` for optimistic UI.

1. Navigation to `/retirement` works and loads without errors.

3. Settings are correctly saved to and loaded from `localStorage`.
